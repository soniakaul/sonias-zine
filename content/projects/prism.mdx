Prism is a personal build log — one row per project, one cell per day, color intensity reflecting how much focused work happened. The pattern is borrowed shamelessly from GitHub&rsquo;s contribution graph; the value is that *non-code* work counts too. A day spent writing a PRD or thinking through architecture is real work, and Prism gives it a square on the grid.
